# whoami — 3-person test script (~10 min each)

Goal: check whether confused people leave **oriented**, not whether they “like the design.”

## Who to ask
3 people who’ve heard AI buzzwords (RAG, agents, transformers) but don’t feel solid. Not AI engineers if you can avoid it.

## Setup
- Give them the live URL (or laptop).
- Say only: “You’ve heard a term and feel lost. Use this to place it.”
- Don’t coach. Watch silently.

## Tasks (pick 2–3)
1. Search **RAG** (or a term they’ve heard).  
2. Open the card. Read without help.  
3. Click one **neighbor**.  
4. Optional: open **Go a little deeper**.

## Ask after (yes/no + one sentence)
1. Where does this sit in AI? (parent / chapter is enough)  
2. What is it *not*?  
3. What would you look at next?  
4. Did you want a course, or was placement enough?

## Pass / fail
| Pass | Fail |
|---|---|
| Can place the idea in ~3 minutes | Stuck or lost on the map |
| Names one clear next step | Asks for a full course immediately |
| Finds search → card useful | Ignores search / only wanders |

## Log (copy per person)
- Person:  
- Term used:  
- Oriented? Y/N  
- Wanted a course? Y/N  
- One quote:  
- One fix you’d make:  

## After all 3
- If 2+ pass → deploy is validated; next = shareable link polish.  
- If 2+ fail → fix orientation (copy, search, card), don’t add forests/features.
